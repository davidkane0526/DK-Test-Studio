# DK Test Studio

独立的 Keithley 4200A-SCS 科研测试控制系统（开发中）。本仓库与 [DK Data Studio](https://github.com/davidkane0526/DK-Data-Studio) 分离，目标是逐步承担 Clarius 的**日常实验操作界面**，并保留仪器端 KXCI 与必要的原厂驱动。

## 当前安全边界

- **第一阶段只读**：真实仪器仅允许 `*IDN?\0` 身份识别，不执行 SMU/PMU 电压输出、扫描或脉冲。
- **Windows 优先**：独立桌面界面、自动连接、简洁卡片和可折叠诊断。Android 与 LAN 中继将在后续完成独立宿主迁移。
- **原始数据真实性**：仪器端原始响应/文件必须原样保存；本地重绘曲线不属于仪器原生图像。
- **不修改原仓库**：首次迁移以 DK Data Studio 的 `4200` 分支为来源，优先复用已测试的 TCP / KXCI 通信代码。

后续代码、测试、构建流程和使用说明将以该仓库为唯一新开发入口。只有在真实模块库存、设备限制与故障保护通过验证后，才会开放输出命令。
