# 4200A 能力与时序界面

## 实装能力与界面

| 模块 | 界面当前可用 | 接续设计 |
|---|---|---|

## LabExpress 页面到 DKTS 的时序映射

库内 V5、V6 转录将 IVT 定位到 LabExpress 2022.01 PDF 第 42–43 页，确认 Time Xsweep 和 Table Input 分开，施加偏置与数据采样各有其步长。Pulse I–V 位于第 44–45 页。FastIV／WaveForms 的独立 Measure Event 位于第 61–66 页，DKTS 借用该事件设置结构。概伦公开产品资料第 2 页可核对 IVT 的时域波形示例，完整参数页的逐项截图对照需要私有原始手册。 [LabExpress 结构转录](reference/4200a/FSPro_UI_Replica_Implementation_V6.extracted.md) · [概伦 FS-Pro 产品资料](https://www.primarius-tech.com/uploads/20230307/EN_FS-Pro.pdf)

- **扫描**填写源通道与波形。Time Xsweep 的方式下拉目前提供 Linear Step。时间偏置表按已映射的 SMU 分别设置电压或电流，分别保留 V 和 A 值。每行持续时间之和是单周期终止时间。公共切换步长给出输出更新时间网格，每行持续时间须对齐该网格。用户提供的 FS-Pro 示例中 Stop 为 1 s、Switching Step 为 0.1 s，对应 10 个 Segments。DKTS 将其显示为「切换步数」，与表中偏置时段的行数区分。计划采样步长定义采样网格，目标页定义实际计划的读出事件。保持特性可按线性或对数调度读出，从保持起点计时。Pulse I–V 显示基线或幅值扫描与平顶参数。
- **目标**定义 Measure Event。每个事件保存端子、起点、窗口、间隔、平均方式及点数。保持特性的读出窗口要小于相邻事件间距。脉冲窗以 UI 平顶起点为参考，底层适配在核实 KXCI 模式的参考点、单位和宽度定义后转换。任意波形可以在横向时间轴上同时检查通道边沿和各测量窗。
- **策略**定义循环、触发、同步、调度路径和异常处理。慢速 SMU 轮询需记录真实时间戳和计划偏差，将读出窗口、仪器积分和稳定时间分开。高速 PMU 由仪器执行时序。多通道触发要核对共享时钟、同步设置和通道偏差。不能把平台定时器当成 PMU 采样时钟。
- **数据与图窗**按流程、测试和采集 ID 保存。将计划值、真实 V/I 采样点、设备时间、主机接收时间和缺失或过载状态分字段保存。时间曲线只使用存在时间及对应 V/I 列的数据。流程层合并子测试可用图形，单项测试只提供与该模式相关的图形。

参数合法时自动保存。无效输入保留在当前工程的编辑区，字段和页内说明标出问题，工程树运行按钮禁用。时间扫描的 Ref Node 按地参考显示，Ref (V) 为 0，Outputs 从目标页的测量事件生成。4200A 的 SMU 可以输出电压或电流。计划值按已核验模块的输出上限检查，实际执行还需验证保护、负载、时序和关断。 [Tektronix 4200A-SCS 安装和维护手册，第 1-3 页](https://download.tek.com/manual/4200A-908-01E_Setup_Maint_April_2024.pdf)

## 接续顺序与验收

1. 从 `plugin.js` 的 `renderTime` 和 `paintTimePreview` 接续。预览绘制有效时间网格上的计划偏置，有效的测量事件用短条显示。用固定手册和固件确认采样、缓冲和停止路径，再用计划及实测快照核查切换和采样顺序。对长时调度、跨段事件、漏样和设备重启保留时间不连续标记。
2. 为保持特性建立 SMU 执行适配。核对 0 V 偏置与开路保持的物理区别；当前界面规划的是偏置保持，开路要单列模式并验证路由。实测验证每次读出后恢复保持、真实间隔、超限和停止关断。
3. 为 PMU 分别接入 Pulse I–V 与 Waveform Capture，再接入每通道的 Segment ARB 和 Measure Event 表。复核负载、量程、采样点数、每个条件下的时序和分块读取，保留段号与原始数据。确认未达到边界、精度和缺失点处理后再进入可输出验收。
4. 对不同模块、Windows 和 Android 进行实际接线、急停、异常断线与安装回退验收。时间扫描、保持特性和脉冲扫描支持编辑、保存及离线校验，执行仍由项目现有的生产门禁拦截。

## 2026-11-24 时序字段复核

- 时间扫描的采样步长提供计划预设和自定义数值。实际 SMU 积分提供仪器默认、0.1、1 和 10 PLC。换算需核对实机线频，读出周期还要包含稳定和测量开销。旧项目以秒保存的积分时间可查看和替换。KXCI Rev F 的 IN 是读数后的等待时间。单次 NR 文档上限为 4096。 [KXCI Rev F，第 5 节](https://download.tek.com/manual/4200A-KXCI-907-01F_Sept2026.pdf)
- PMU 采样率根据测量窗、扫描点数和每点脉冲数筛选预设，合法区间内可填整数。周期、边沿和关断间隔同时采用测量模式规格和 KXCI 电压档限制。固定电流档由实装 PMU、RPM、通道和电压档决定。旧保持和基线延迟仅显示已保存值，待落实硬件映射。 [KXCI Rev F，第 7 节](https://download.tek.com/manual/4200A-KXCI-907-01F_Sept2026.pdf) · [脉冲卡 Rev D，第 3–4 节](https://download.tek.com/manual/4200A-PMU-900-01D_Sept_2026.pdf)

## 时间扫描的采样与输出

- LabExpress 的 Switching Step 定义偏置更新的时间网格，Sampling Step 定义另一条采集时间网格。两个设置分别对应输出和采集。 [LabExpress 参数结构转录](reference/4200a/FSPro_LabExpress_to_DKTS_Implementation_V5.extracted.md)
- DKTS 的「分段脉冲 · PMU」用每行保持时间定义输出，「扫描」的采样项可在步长和频率之间切换。线性步进也支持切换计划采样参数。PMU 软件按采样步长的倒数编译 KXCI `:PMU:SAMPLE:RATE`，检查最短测量窗口和采样缓冲。逐点输出使用仪器时间戳。SMU 固定偏置的 IN 控制读数后的等待，实际点间时间还含积分及读出。SMU 列表以点数和 DT 稳定等待表达。 [KXCI 手册，第 5、7 节](https://download.tek.com/manual/4200A-KXCI-907-01E_March2025.pdf)
- 分段脉冲的自动过渡逐边取 KXCI 最短段时间、该量程和电平的时序规格，以及所选实装 PMU/RPM 电流档的已公布典型建议中的较大值，按 10 ns 时间格向上取整。未确认硬件时按 4225-PMU 规格预览，接线和 DUT 波形仍以实测为准。 [硬件典型建议](https://download.tek.com/datasheet/1KW-60780-6_4200A-SCS_Parameter_Analyzer_Datasheet_050724.pdf)

- 「时间偏置 · SMU」共用一张表。新增第二段时保留首段点数并启用仪器列表，删回单段时使用固定偏置的首次等待和读数后等待。单段旧列表按原方案载入。PMU 电压档由峰值和负载线推断。

- SMU 预览可以切换点号与估算时间。点号从 1 开始，点数包含首末点。固定偏置估算按首次等待加已完成点之间的读数后等待，SMU 列表按每点稳定等待累计。积分、读出与设备开销由仪器实际时间戳体现。等待字段旁的问号显示分阶段时序示意。

- SMU 和 PMU 计划预览使用 Core PlotView。「显示」设轴或切换单位及测量窗口，「数据」可导出计划 CSV 或打开实测图窗。计划预览按波形编排，导出不产生实测数据记录。SMU 的 WT/IN、DT 位于偏置表。PMU 的估计负载对实际变阻器件仅作补偿和校核，当前为空时可编辑计划，仪器运行路径要求已确认负载。
