# 4200A 能力与时序界面

## 实装能力与界面

| 模块 | 界面当前可用 | 接续设计 |
|---|---|---|
| SMU 与前置放大器 | 连接后识别实际通道。DC 端子设置按已核验的型号、前放和设定电压筛选量程。保持特性可编辑初始、保持、读出偏置和读出调度。 | 在对应端子上显示量程来源、保护值和互锁核验状态，给出高压、功率、限流冲突的字段定位。保持特性需核对切换延时、稳定时间和读出窗口。 |
| 4225-PMU | 脉冲扫描可规划基线或幅值扫描、上升／下降、平顶、周期、测量窗、采样率和计数。预估每通道采样点。已识别 PMU 的物理通道与 RPM 决定候选电流档。 | 将 Pulse I–V 的窗内均值与 Waveform Capture 的波形点分别映射、验收。预览覆盖基线、平顶、采集窗口与延迟。用 KXCI 生成点数及缓冲区验证采样预算。 |
| 4225-RPM | 使用 PMU 卡内通道的附件归属显示可选电流档。 | 显示每个通道的附件、路由、稳定时间和切换状态。只有在 PMU、SMU 或 CVU 的对应路由及实装附件核验成功后才容许执行切换。 |
| 4220-PGU | 能力库将它标为脉冲源，当前脉冲测量编辑器使用 PMU。 | 在波形编辑器允许 PGU 源通道，测量事件必须另指向已验证的采集通道。 |
| CVU 与 CVIV | 能力库区分 4210／4215 和 CVIV，C–V 专用参数与图形待接入。 | 增加频率、AC 激励、DC 偏置、夹具补偿和路由字段。扩展偏置需显示实际电源选件、偏置 SMU 和开关配置。 |

## LabExpress 页面到 DKTS 的时序映射

库内 V6 转录将 IVT／表格输入定位到 LabExpress 2022.01 PDF 第 42–43 页，Pulse I–V 定位到第 44–45 页，FastIV／WaveForms 与测量事件定位到第 61–66 页。本轮参照这些页码和结构整理界面，原厂截图对照需要私有原始手册。 [LabExpress 结构转录](reference/4200a/FSPro_UI_Replica_Implementation_V6.extracted.md)

- **扫描**填写源通道与波形。在 Time Xsweep 中依次列出区段、时间、持续时间和偏置，切换步长与采样步长独立。保持特性可按线性或对数调度读出；时间从保持起点计算。Pulse I–V 单独暴露基线或幅值扫描与平顶参数。
- **目标**定义 Measure Event。每个事件保存端子、起点、窗口、间隔、平均方式及点数。保持特性的读出窗口要小于相邻事件间距。脉冲窗以 UI 平顶起点为参考，底层适配在核实 KXCI 模式的参考点、单位和宽度定义后转换。任意波形可以在横向时间轴上同时检查通道边沿和各测量窗。
- **策略**定义循环、触发、同步、调度路径和异常处理。慢速 SMU 轮询需记录真实时间戳和计划偏差，将读出窗口、仪器积分和稳定时间分开。高速 PMU 由仪器执行时序。多通道触发要核对共享时钟、同步设置和通道偏差。不能把平台定时器当成 PMU 采样时钟。
- **数据与图窗**按流程、测试和采集 ID 保存。将计划值、真实 V/I 采样点、设备时间、主机接收时间和缺失或过载状态分字段保存。时间曲线只使用存在时间及对应 V/I 列的数据。流程层合并子测试可用图形，单项测试只提供与该模式相关的图形。

## 接续顺序与验收

1. Time Xsweep 已可编辑分段偏置、切换步长、采样步长、循环次数、积分时间和测量事件。事件支持端子、I/V、起点、窗口、间隔及点数。继续接入波形和测量事件预览，用固定手册和固件确认采样、缓冲和停止路径，再用快照测例核查切换和采样顺序。对长时调度、跨段事件、漏样和设备重启保留时间不连续标记。
2. 为保持特性建立 SMU 执行适配。核对 0 V 偏置与开路保持的物理区别；当前界面规划的是偏置保持，开路要单列模式并验证路由。实测验证每次读出后恢复保持、真实间隔、超限和停止关断。
3. 为 PMU 分别接入 Pulse I–V 与 Waveform Capture，再接入每通道的 Segment ARB 和 Measure Event 表。复核负载、量程、采样点数、每个条件下的时序和分块读取，保留段号与原始数据。确认未达到边界、精度和缺失点处理后再进入可输出验收。
4. 对不同模块、Windows 和 Android 进行实际接线、急停、异常断线与安装回退验收。时间扫描、保持特性和脉冲扫描支持编辑、保存及离线校验，执行仍由项目现有的生产门禁拦截。
